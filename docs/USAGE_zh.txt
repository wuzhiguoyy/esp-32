道玄 AI 语音助手 · ESP32-S3 通用固件 使用说明
================================================

一、适用硬件
------------------------------------------------
- ESP32-S3 开发板（Flash 8MB 及以上，带 PSRAM 更好）- 麦克风模块（I2S，如 INMP441）
- 喇叭 + 功放（如 MAX98357A）
- USB 数据线

二、接线（默认配置）
------------------------------------------------
麦克风 I2S：
  SCK  -> GPIO 4
  WS   -> GPIO 5
  SD   -> GPIO 6
  VDD  -> 3.3V
  GND  -> GND

喇叭 I2S：
  BCLK -> GPIO 15
  LRC  -> GPIO 16
  DIN  -> GPIO 17
  VIN  -> 5V
  GND  -> GND

如引脚不同，请自行编译固件并修改板型配置。

三、烧录步骤
------------------------------------------------
1. 安装 Python 3.10 及以上：https://www.python.org/downloads/
2. 安装烧录工具：
   pip install esptool
3. 用 USB 线连接开发板，查看串口号（设备管理器 -> 端口）
4. 在本文件夹打开命令行，执行（COM3 换成你的串口）：
   python -m esptool --chip esp32s3 -p COM3 -b 921600 write-flash 0x0 firmware.bin
5. 看到 Hard resetting 表示烧录完成

四、激活步骤
------------------------------------------------
1. 设备首次开机进入配网模式，连接热点 Daoxuan-xxxx
2. 打开 http://192.168.4.1 配置 Wi-Fi
3. 设备联网后，串口会打印激活码：
   ACTIVATION CODE: 123456
   也可用串口工具（115200）查看
4. 打开网站注册账号，进入「我的设备」
5. 输入 6 位激活码，绑定成功
6. 说「你好小智」开始对话

五、常见问题
------------------------------------------------
Q: 烧录失败？
A: 换 USB 数据线（不是充电线），按住 BOOT 再点 RST 进入下载模式。

Q: 找不到串口？
A: 安装 CH340 / CP210x 驱动。

Q: 没有声音？
A: 检查喇叭接线和功放供电，音量默认 50%。

Q: 看不到激活码？
A: 用串口工具打开 115200 波特率，按 RST 重启。
